# ViT＋分類頭能不能看出 K 線型態（2026-11-16）

分支：`Yn/v2_vit`。主線（`Yn/v2`）的架構仍是凍結 ViT；這份是另外的探索實驗，還沒接進融合層或 Decoder。

## 摘要

標籤是 Haiku 讀同一張 K 線圖判的 7 類型態，所以這裡量的是「ViT 能多像 Haiku 那樣讀圖」。Test 準確率（3 個 seed 平均）：

| 做法 | AAPL | NVDA |
|---|---:|---:|
| 多數類 baseline | 0.315 | 0.128 |
| 融合層（mask_ht）＋ probe | 0.596 | — |
| 凍結 ViT＋邏輯迴歸（最好的特徵） | 0.660 | 0.547 |
| 只解凍最後 2／3／4 層 | 0.563／0.617／0.647 | — |
| 全參數微調，單一股票 | 0.726 ± 0.022 | 0.668 ± 0.011 |
| 全參數微調，K 線＋成交量雙圖 | 0.742 ± 0.019 | — |
| **全參數微調，AAPL＋NVDA 合併訓練** | **0.759 ± 0.018** | **0.744 ± 0.032** |

- 型態資訊在圖裡讀得到，但目前凍結 ViT＋融合層沒有萃取出來。
- 要整個 ViT 一起調才有效；只解凍最後幾層反而比凍結還差。
- 多支股票一起訓練比單一股票好，3 個 seed 都是。
- 盤整幾乎判不出來（大多被判成頂部反轉），多加資料也沒改善。

## AAPL 單一股票

問題：只看 K 線圖，ViT 加上分類頭能不能判出 Haiku 給的 7 類型態？

設定：
- 標籤來自 `data/labels/chart_caption/AAPL.json` 的 pattern。
- 切分用全專案的 strict temporal manifest：966／202／203 天。
- 程式：`experiments/vision/vit_pattern.py`（訓練與評估）、`experiments/vision/vit_pattern_confusion.py`（畫 confusion matrix）。
- 輸出：`data/outputs/experiments/vit_pattern/`（不進版控）。
- **凍結**：讀 B 存好的 H_v，取 CLS 或 patch 平均，接 Logistic Regression（class_weight balanced）。Validation 選 C，再用 Train＋Validation refit。
- **微調**：`google/vit-base-patch16-224` 整個微調，接線性頭。
  - 訓練設定：class-weighted CE，lr 2e-5（頭 1e-3），OneCycle，10 個 epoch，batch 16。
  - 不做翻轉之類的資料增強，因為左右翻轉會把上升變成下降。
  - 依 Validation macro F1 選 epoch。

| 做法 | Test 準確率 | Test macro F1 |
|---|---:|---:|
| 多數類 baseline | 0.315 | — |
| 融合層（mask_ht）＋ probe（run 20261105_230521） | 0.596 | 0.440 |
| 凍結 ViT，K 線圖 CLS | 0.601 | 0.451 |
| 凍結 ViT，K 線圖 patch 平均 | 0.660 | 0.476 |
| 凍結 ViT，兩張圖 CLS／patch 平均 | 0.596／0.611 | 0.453／0.466 |
| **微調 ViT，K 線圖（seed 42／43／44）** | **0.749／0.704／0.724，平均 0.726 ± 0.022** | **0.593／0.536／0.548，平均 0.559 ± 0.030** |
| 微調 ViT，兩張圖 CLS 串接（seed 42／43／44） | 0.764／0.729／0.734，平均 0.742 ± 0.019 | 0.582／0.580／0.565，平均 0.575 ± 0.009 |

（± 是 3 個 seed 的樣本標準差。）

- **看得出來，而且微調明顯比凍結好**：準確率比凍結版高約 0.07～0.13，比多數類高約 0.4。
- **融合層目前沒有比原始 ViT 多學到型態**：凍結 ViT 的 patch 平均已經略好於融合層的 mask_ht probe。
- **加上成交量圖（3 個 seed）幫助很小**：
  - 同 seed 比，準確率 3 個 seed 都略高（+0.015／+0.025／+0.010，平均 +0.016，約等於 Test 多對 3 天）；macro F1 是 −0.011／+0.044／+0.017。
  - 差距在 seed 間的波動範圍內，不能說有幫助。
  - 各類 recall 有交換：突破 0.48 → 0.67、底部反轉 0.53 → 0.61，但跌破 0.50 → 0.28（Test 只有 18 筆，多被判成持續下跌）。盤整還是幾乎全錯（0.04）。
- **各類 recall**（K 線圖，3 個 seed 合計；confusion matrix 圖：`confusion_test.png`）：
  - 上升 0.90、反轉頭部 0.83、下降 0.76、反轉底部 0.53、跌破 0.50、突破 0.48、**盤整 0.00**（Test 只有 8 天，大多被判成反轉頭部）。
  - 錯誤集中在相鄰型態：突破 ↔ 上升、反轉底部 → 上升／突破、下降 → 反轉頭部／跌破。這些也是 Haiku 標籤可能不穩的地方。
- **Overfit 明顯**：訓練集準確率到 0.99，靠 Validation 選在第 5～8 個 epoch 停止。
- **含意**：
  - 型態資訊在圖裡是讀得到的，凍結 ViT 加上融合層沒有把它萃取出來。
  - 「ViT 微調」原本只列為規劃（#120）。這個結果支持把它提前，或至少讓 ViT 最後幾層可以訓練。
  - 這只是一個 probe，還沒接進融合層或 Decoder。

## 只解凍最後幾層（K 線圖，3 個 seed）

想減輕過擬合，改成只訓練最後 N 層 Transformer＋最後的 LayerNorm＋分類頭，embedding 與前面的層凍結。其他設定跟全參數微調完全一樣（lr 2e-5、頭 1e-3、10 個 epoch、batch 16）。程式：`experiments/vision/vit_pattern.py finetune --unfreeze N`。

| 解凍層數 | 可訓練參數 | Test 準確率（seed 42／43／44） | 平均 | macro F1 平均 | 選中 epoch | 選中 epoch 的 Train 準確率 |
|---|---:|---|---:|---:|---|---|
| 2 層 | 14.2M | 0.557／0.547／0.586 | 0.563 ± 0.020 | 0.460 ± 0.013 | 9／8／7 | 0.75／0.72／0.74 |
| 3 層 | 21.3M | 0.611／0.611／0.631 | 0.617 ± 0.011 | 0.481 ± 0.012 | 5／9／8 | 0.77／0.82／0.84 |
| 4 層 | 28.4M | 0.640／0.670／0.631 | 0.647 ± 0.021 | 0.503 ± 0.017 | 6／9／7 | 0.85／0.88／0.87 |
| 全部（12 層＋embedding） | 85.8M | 0.749／0.704／0.724 | **0.726 ± 0.022** | **0.559 ± 0.030** | 6／5／5 | 0.98／0.95／0.94 |

- **解凍越少越差，2～4 層都輸給全參數微調**，2、3 層甚至比凍結 ViT＋邏輯迴歸（patch 平均 0.660）還低。
- 過擬合確實減輕（Train 準確率從 0.95～0.98 降到 0.72～0.88），但變成學不夠：Validation macro F1 只到 0.51～0.54（全參數 0.64）。
- 推測：K 線圖跟 ImageNet 差很遠，前面幾層（看線條、色塊的那幾層）也需要調整；只動最後幾層不夠。
- 注意：
  - 學習率和 epoch 沿用全參數的設定，沒有替部分解凍另外調。
  - 選中的 epoch 多在 7～9，表示 10 個 epoch 可能還沒訓練完；調高學習率（例如 1e-4）或加 epoch 可能會再好一些。

## 換 NVDA 再跑一次（K 線圖，3 個 seed）

- NVDA 原本沒有 K 線敘述，先用 `module_a_data.chart_caption --ticker NVDA` 跑完 1,381 天（Haiku，input 約 197 萬、output 約 120 萬 token），存成 `data/labels/chart_caption/NVDA.json`。
- 型態分布跟 AAPL 接近：持續上漲 404、頂部反轉 267、持續下跌 259、底部反轉 250、突破 145、盤整 39、跌破 17。
- 切分一樣是 966／202／203 天，設定跟 AAPL 完全相同（凍結版、全參數微調）。程式：`experiments/vision/vit_pattern.py ... --ticker NVDA`，輸出檔名加 `NVDA_` 前綴。

| 做法 | NVDA Test 準確率 | NVDA macro F1（7 類／6 類） | AAPL Test 準確率 |
|---|---:|---:|---:|
| 多數類 baseline（Train 最多的類） | 0.128 | — | 0.315 |
| 凍結 ViT，K 線圖 CLS／patch 平均 | 0.547／0.502 | 0.394／0.382 | 0.601／0.660 |
| 凍結 ViT，兩張圖 CLS／patch 平均 | 0.507／0.542 | 0.351／0.382 | 0.596／0.611 |
| **微調 ViT，K 線圖（seed 42／43／44）** | **0.675／0.675／0.655，平均 0.668 ± 0.011** | **0.517 ± 0.016／0.603 ± 0.019** | 0.726 ± 0.022 |

- **NVDA 的 Test 沒有任何一天是跌破**，但 macro F1 照樣算 7 類，跌破那類固定是 0，會把平均拉低約 1/7。「6 類」是去掉跌破後的 macro F1，比較能代表實際表現。
- 多數類 baseline 很低（0.128），因為 Train 最多的是持續上漲，Test 期間持續上漲只有 26 天；Test 最多的是頂部反轉（58 天，0.286）。
- **結論跟 AAPL 一致**：微調明顯好於凍結，而且差距更大（NVDA 約 +0.12，AAPL 約 +0.07）。
- 各類 recall（3 個 seed 合計）：頂部反轉 0.75、持續下跌 0.71、持續上漲 0.68、底部反轉 0.60、突破 0.58、盤整 0.38。
  - 盤整在 AAPL 是 0，NVDA 判對 38%，但仍有 42% 被判成頂部反轉，跟 AAPL 是同一種混淆。
  - 持續上漲、持續下跌各有約 18～19% 被判成頂部反轉。
- confusion matrix：`NVDA_confusion_test.png`。

## AAPL＋NVDA 合併訓練（K 線圖，3 個 seed）

- 兩支股票各用自己的 manifest 切，再把同名的組合併：Train 1,932／Validation 404／Test 406 天。Test 期間的資料不會進訓練。
- 一個模型同時學兩支股票；設定跟單一股票完全相同；依合併後的 Validation macro F1 選 epoch；Test 再分股票各評一次。
- 程式：`experiments/vision/vit_pattern.py finetune --ticker AAPL+NVDA`，輸出 `AAPL+NVDA_finetune_candlestick_seed*.json`（`test_by_ticker` 是分股票的結果）。每個 seed 約 30 分鐘（M5 MPS）。

| Test | 單一股票訓練（seed 42／43／44） | 合併訓練（seed 42／43／44） | 同 seed 差 |
|---|---|---|---|
| AAPL 準確率 | 0.749／0.704／0.724，平均 0.726 ± 0.022 | 0.754／0.744／0.778，**平均 0.759 ± 0.018** | +0.005／+0.039／+0.054 |
| AAPL macro F1 | 0.559 ± 0.030 | **0.593 ± 0.010** | |
| NVDA 準確率 | 0.675／0.675／0.655，平均 0.668 ± 0.011 | 0.714／0.739／0.778，**平均 0.744 ± 0.032** | +0.039／+0.064／+0.123 |
| NVDA macro F1（7 類／6 類） | 0.517／0.603 | **0.572／0.667** | |

- **合併訓練兩支都變好，3 個 seed 全部都是正的**：AAPL 平均 +0.033，NVDA 平均 +0.076。資料加倍對 NVDA 幫助比較大。
- 各類 recall（3 個 seed 合計，AAPL／NVDA）：持續上漲 0.90／0.76、持續下跌 0.75／0.84、頂部反轉 0.93／0.80、底部反轉 0.57／0.69、突破 0.64／0.67、跌破 0.39／—（NVDA Test 沒有）、盤整 0.04／0.21。
  - 盤整還是幾乎判不出來：AAPL 0 → 0.04，NVDA 反而從 0.38 降到 0.21（Test 各只有 8 天，3 個 seed 共 24 筆）。突破、頂部反轉明顯變好。
- 過擬合仍在：選中 epoch 時 Train 準確率 0.99；選中的 epoch 是 8／9／9，比單一股票晚。
- **含意**：型態判讀可以跨股票共用，資料越多越好；接進架構時 ViT 適合用多支股票一起訓練。下一步可以加 MSFT（要先補 Haiku 敘述）或做跨股測試（AAPL 訓練、NVDA 測試）。
